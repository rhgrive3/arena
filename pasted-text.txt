 ## 遊び方
 
-1. 「戦場へ」で配置フェーズに入ります(16対16の初期部隊。時間と資金回復は停止中)。
-2. 下部の**勢力タブ**(王国軍・蛮族・神秘・不死)から兵種カードを選び、青い自陣をクリック/タップして増援を配置します。
-   配置したキャラは空から落下して着地します。「×5」ボタンかShift+クリックで最大5体をまとめて配置できます。
-3. 「戦闘開始」で両軍が自動交戦します。部隊を選択して移動や集中攻撃を指示できます。
-4. どちらかの軍が全滅すると増援が止まり、残った飛び道具の着弾後に決着します。両軍全滅は引き分けです。
+- **ストーリー**: 全4章・20ステージの戦役モード。敵の編成と地形障害物に合わせて予算内で部隊を配置し、勝利すると次のステージと新しい兵種が解放されます（戦闘中の資金回復や増援はありません）。
+- **カスタム戦**: 全25兵種を使用可能。「味方配置 / 敵配置」で両軍を自由に編成でき、「全消去」でゼロから組めます（予算は各軍3000、各軍上限50体）。「戦場」ボタンで4つの戦場マップ（障害物付き）を自由に切り替えられます。
+- **兵種図鑑**: 全25兵種が正面を向いて整列し、ドラッグで回り込んで造形やサイズ感を観察できます。
 
-「兵種見本を見る」(メニュー)では、全15兵種が正面を向いて並び、名前と役割が表示されます。右ドラッグで回り込んで観察できます。

+### 戦闘ルール・戦術要素
 
-### 操作
+- **方向ダメージと盾ブロック**: 側面・背後からの攻撃はダメージが **1.3倍** になります。逆に盾を持つ兵種（盾兵・剣士・聖騎士）が正面から攻撃を受けると、基本防御に加えて盾による追加軽減が発動し白い火花が散ります。
+- **ノックバックと吹っ飛び物理**: 衝撃力の強い攻撃（重騎兵の突撃、巨人、爆弾など）を受けると空中に吹き飛ばされ、着地後に地面を滑って一時行動不能になります。トドメの一撃でも勢いを保ったまま吹っ飛びます。
+- **戦場の地形障害物**: 各章の戦場（辺境の荒野・裂け谷・霜の峠・王都決戦）には石碑や岩柱などの障害物があり、部隊は障害物を避けて側方へ自動迂回します。

+  z: number;
+  radius: number;
+  height: number;

+  1: [{ x: 0, z: -19, radius: 3.6, height: 3 }, { x: 0, z: 19, radius: 3.6, height: 3 }],

+    { x: 0, z: 12, radius: 3.4, height: 7 },
+    { x: 16, z: -27, radius: 3.4, height: 7 },
+    { x: 16, z: 27, radius: 3.4, height: 7 },
+  ],
+};
+
+export function terrainObstacles(scene: number): readonly TerrainObstacle[] {
+  return OBSTACLES[scene] ?? OBSTACLES[0];
+}
+
+export function terrainClear(scene: number, x: number, z: number, radius = 0) {
+  return terrainObstacles(scene).every(o => Math.hypot(x - o.x, z - o.z) >= o.radius + radius + 0.1);
